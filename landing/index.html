One terminal. Every conversation.

Discord and Matrix in a single keyboard-driven TUI, without violating either platform's terms of service.

Your user account never touches the gateway.

Every other terminal Discord client works by self-botting: it drives your personal user account against Discord's gateway, which violates the terms of service and puts your account at risk of suspension. That trade has always been the price of a Discord TUI.

Marga refuses to ship a self-bot. Discord traffic goes through a server-side bot and webhook relay, so your user account never touches the gateway and stays compliant. Matrix has no such restriction, so Marga connects to your homeserver directly, end-to-end encryption included. Same keyboard, two networks, zero terms broken.

Networks are adapters. The stream is the product.

adapter model

One TUI, multiple networks

Every network is a pluggable adapter behind a single Network interface, and every adapter feeds one unified event stream. The interface you learn once works everywhere.

discord relay

ToS-safe Discord access

Messages travel through a server-side bot and webhook relay instead of a self-bot. Your user account never authenticates against the gateway and stays compliant.

matrix direct

Direct, relay-free Matrix

Matrix needs no intermediary, so Marga speaks to your homeserver straight over mautrix-go. No relay, no extra hop, no third party in the path.

encryption

Transparent end-to-end encryption

Encrypted Matrix rooms decrypt automatically through a pure-Go goolm backend. Keys are generated and stored locally; you never handle them by hand.

spaces

Matrix spaces as servers

Joined Matrix spaces surface as switchable servers in the sidebar, so the mental model matches Discord: pick a server, pick a channel, type.

local-first

Local-first secrets and history

Tokens live in your OS keyring, never in config files. Message history lands in SQLite, so /search works offline across everything you have seen.

From clone to chat.

Go 1.25 or newer. The first run launches a setup wizard that walks you through connecting each network.

marga - zsh
$ git clone https://github.com/kunthive-Labs/Margana.git && cd Margana $ make build $ ./bin/marga # first run launches the setup wizard # or install directly: $ go install -tags goolm github.com/kunthive-Labs/Margana/cmd/marga@latest

Honest about version 0.1.0.

This is a first release, and the page says so. No credentials or shared infrastructure endpoints are embedded in the binary. What ships is what the code does today, and here is where the edges are.

Build from source, for now

There is no Homebrew formula and there are no pre-built packages yet. v0.1.0 is a make build away, and the Go toolchain is the only prerequisite.

Trust on first use

The Matrix device verification UI is not built yet, so new devices are trusted on first use. Encrypted rooms still decrypt; interactive verification is on the roadmap.

Bring your own relay

The default Discord relay endpoints in the sample config are placeholders. You point Marga at a bot and relay you control; nothing shared is baked in.
