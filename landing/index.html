What it is

Several chat networks, one event stream.

Marga is a single full-screen TUI that talks to multiple chat networks at once. Each network plugs in behind a common Network adapter, so the interface consumes one unified, fan-in event stream and never sees protocol-specific wire formats. Switch networks with a keystroke; everything looks and feels the same.

Today it speaks Discord — through a server-side relay bot, so your account stays ToS-compliant — and Matrix — connected directly to your homeserver, with encrypted rooms decrypted transparently and joined spaces surfaced as switchable servers. The adapter model is pluggable, so more networks can follow.

Features

Built for people who live in the terminal.

One TUI, many networks

A unified Bubble Tea interface over a fan-in Events() stream. The UI never touches network-specific wire formats — switch with Ctrl+T.

Matrix, end-to-end encrypted

Connects straight to your homeserver via mautrix-go. Olm/Megolm E2EE rooms are decrypted and encrypted transparently; keys live locally, the token in your OS keyring.

Discord without self-botting

Discord forbids driving a user account against its gateway. Marga connects through a server-side bot + webhook relay instead, so your account stays ToS-compliant.

Local full-text search

Message history is persisted to SQLite with an FTS5 full-text index. /search runs prefix-matched queries over everything you've seen — offline.

Pluggable adapters

Every network implements one Network interface. Add a new backend without touching the TUI — the event bus and UI stay network-neutral.

Keyboard-first & agent-ready

Slash commands, completion for @user / #channel, and rich shortcuts. Headless-friendly env-var auth makes it usable by agents and CI, not just humans.

How it works

Adapters fan in. The TUI reads one stream.

1

Network adapters

Discord (relay + websocket) and Matrix (direct, mautrix) each implement the common Network interface.

2

Unified event bus

Every adapter emits onto a single fan-in Events() channel — one normalized stream, no wire formats leaking out.

3

Live Bubble Tea TUI

The terminal UI consumes that stream and renders channels, messages, users and networks in real time.

4

SQLite + FTS5

Messages persist to a local SQLite store with a full-text index, so history and /search work offline.

Tech stack

Pure Go, no C toolchain required.

The goolm build tag selects mautrix's pure-Go Olm backend for Matrix E2EE, so no system libolm or CGo is needed. SQLite is the CGo-free modernc.org/sqlite driver.

Get started

Build from source, run in seconds.

Marga is built from source and needs Go 1.25+. First run launches an interactive setup wizard.

 clone & build
# clone and build the binary
git clone https://github.com/kunthive-Labs/Margana.git
cd Margana
make build          # → bin/marga (sets -tags goolm)
./bin/marga
 install with Go
# install the binary directly
go install -tags goolm \
  github.com/kunthive-Labs/Margana/cmd/marga@latest

# then launch the setup wizard
marga

Matrix needs no relay — add a [[networks]] block with your homeserver and user id, and Marga prompts for your password (stored in the keyring). Discord uses placeholder relay endpoints by default — stand up your own. See docs/SELF_HOSTING.md.
